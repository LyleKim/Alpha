# db_migration

## 책임
CDC 기반 DB 이전을 실행·관리합니다.

- CDC 인프라 구축
- Kafka·Kafka Connect·Debezium 배포·설정
- 초기 복사, 변경분 복제, 검증, 쓰기 전환

`infra/db_migration/`의 IaC·배포 설정·커넥터 템플릿을 사용합니다.
CDC 실행 환경은 FastAPI와 별도로 동작하며, 이 모듈은 이를 구축·제어만 합니다.
데이터는 원본 DB → Source → Kafka → Sink → 목적지 DB로 이동합니다.

## 예상 입력
- 원본·목적지 DB 접속 정보 참조
- 이전 대상 스키마·테이블 범위

## 예상 출력
- 단계별 진행 상태 (복사·복제 지연·검증 결과)
- 쓰기 전환 준비 여부

## 미정 사항 (합의 필요)
- CDC 서버 배치 클라우드
- 검증 기준과 쓰기 전환 절차
- 담당자
